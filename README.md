# Python-Data-Analysis
# 🐍 Python Programming Exercises & Problem Solving

A collection of Python programming exercises focused on algorithmic thinking, data manipulation, and problem-solving using Jupyter Notebook.

### 🎯 Key Topics Covered
- **Core Data Structures:** Working with Lists, Tuples, Dictionaries, and Strings.
- **Algorithmic Thinking:** Loops, conditional logic, finding min/max values, and aggregating/analyzing list data.
- **Clean Code:** Writing modular and reusable functions.

### 📂 Repository Contents
- `python_functions_and_logic.ipynb`: A comprehensive notebook containing various Python problem-solving exercises (functions, logic, list processing, and basic data statistics).

### 🛠️ Tech Stack
- **Language:** Python 3
- **Environment:** Jupyter Notebook / VS Code
